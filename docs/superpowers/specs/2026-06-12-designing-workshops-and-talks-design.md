# Designing Workshops and Talks Skill Design

## Purpose

Create a reusable Codex skill that helps users develop ideas and turn them into
workshops, talks, ideation sessions, mixed formats, or custom deliverables.

The skill supports two modes:

- Fast Start for ideas, inspiration, rough directions, and brainstorming.
- Complete Design for detailed, timed, ready-to-run plans.

Complete Design uses the core sequence:

1. Diverge
2. Cluster
3. Converge
4. Design the selected deliverable

## Interaction Flow

For Fast Start:

1. State brief assumptions instead of blocking on intake.
2. Generate the requested idea count, defaulting to 20.
3. Cluster the ideas, highlight three directions, and ask which to develop.

For Complete Design:

1. Ask for all essential context in one message:
   - Topic
   - Goal
   - Audience
   - Occasion and participant count
   - Constraints
   - Desired outcome
2. Default the idea count to 20 when unspecified.
3. Ask whether ideas should be generated by AI, participants, or both.
4. Generate or facilitate the requested number of ideas.
5. Propose a topic-appropriate clustering method.
6. Recommend convergence criteria, explain the reasoning, and let the user
   adjust them.
7. Cluster and rank the ideas using the confirmed criteria.
8. Recommend 15, 30, or 60 minutes based on depth, interaction, audience, and
   expected outcome. Explain the recommendation and ask for confirmation.
9. Let the user select one or more deliverable types:
   - Workshop activity
   - Talk or presentation
   - Ideation session
   - Mixed format
   - Custom output
10. When multiple types are selected, ask whether to integrate them into one
    flow or produce separate plans.
11. Produce only the confirmed duration version.

## Output Contract

Fast Start outputs assumptions, divergent ideas, themes, promising directions,
and a question about what to develop.

The Complete Design output adapts to the selected deliverable types and
includes the applicable elements:

- Objective and expected outcome
- Confirmed duration and rationale
- Timed agenda
- Content outline or activity instructions
- Facilitator prompts or speaker notes
- Materials and preparation
- Participant or audience outputs
- Risks, fallback options, and scope reductions

The output must be executable rather than a list of abstract suggestions.

## Decision Rules

- Fast Start does not require complete intake.
- Complete Design never skips divergence, clustering, or convergence.
- Default the idea count to 20 when the user does not specify one.
- Support AI-generated ideas, participant-generated ideas, or both.
- Recommend evaluation criteria before asking the user to confirm or adjust.
- Recommend one duration before asking the user to confirm it.
- Do not automatically emit all 15, 30, and 60 minute versions.
- Permit multiple deliverable types.
- For multiple types, do not assume integrated or separate output.

## Skill Structure

Create:

```text
designing-workshops-and-talks/
├── SKILL.md
└── agents/
    └── openai.yaml
```

No scripts, references, or assets are required for the initial version.

## Validation Strategy

Use skill TDD:

1. Run baseline prompts without the new skill and record failures.
2. Write the minimal skill that corrects observed failures.
3. Run equivalent prompts with the skill and compare behavior.
4. Refine instructions when the agent skips required questions, recommends no
   duration, emits all durations, or bypasses divergence and convergence.
5. Run the standard skill validator and inspect all generated files for
   placeholders, contradictions, and non-English code or metadata.

Representative scenarios:

- A vague request to prepare a 30-minute engineering talk.
- A team workshop that needs participant-generated ideas and prioritization.
- A mixed talk and activity where the user has not specified duration or idea
  count.

## Success Criteria

- The skill triggers for workshop, presentation, talk, facilitation,
  brainstorming, and ideation requests.
- Fast Start proceeds from brief assumptions without blocking on intake.
- Complete Design gathers missing information in one batch.
- Complete Design follows diverge, cluster, and converge before final design.
- Complete Design recommends one duration and waits for confirmation.
- It supports multiple output types and asks how to combine them.
- The final plan matches only the confirmed duration.
- Skill validation passes with no placeholder content.
